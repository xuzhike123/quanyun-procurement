# 金额分档与审批链

## R — 原文 (Reading)

> 限额以上采购项目。集团本部及权属企业的所有单项或批量限额以上采购项目及其采购方式统一由交发集团审批决策。

> 限额以下采购项目。集团本部及权属企业的所有限额以下采购项目及其采购方式均由集团公司审批决策。权属企业无审批决策权限，未经集团公司审批同意，不得擅自开展采购活动。

> （1）20万元以上、50万元以下采购项目，提交集团采购领导小组专题会审议决策。（2）50万元以上采购项目，应先提交集团采购领导小组专题会审议决策后，再提交集团领导会议审议决策。

来源：闽泉运综合〔2026〕60号 第二十二条；配套档位见附件2 对照表。

## I — 方法论骨架 (Interpretation)

审批链由三个变量决定，顺序不能颠倒：**估算价 → 预算状态 → 采购主体**。

**第一刀切金额。** 以单项或批量采购估算价计：

- 200 万元及以上，属限额以上，一律报交发集团审批，本企业只能履行内部程序后上报。
- 200 万元以下，属限额以下，一律由泉运集团审批；权属企业没有审批决策权。
- 20 万元以下，属小额，走采购会签单，不必上会。
- 20 万元及以上，必须上会。

**第二刀切主体。** 同一个 50 万元，本部与权属企业的链条不同：本部是"领导小组会 → 总经理办公会"，权属企业是"内部决策 → 报请示 → 领导小组会 → 归口部室按会议意见批复"。

**第三刀切预算状态。** 预算内按档位走；预算外要先取得"同意纳入年度预算"的意见，再研究具体采购事宜；超预算要按权限重新履行审批程序。重新报批的分界点是三条线：单项合同 50 万元、预算增幅 10%、预算增额 50 万元。三条线以内的回到归口部室按原形式审批，超出的重新提交集团领导会。判断依据是超出的原因归属哪一级：原项目由归口部室决策的，增幅 10% 以上的超预算回原层级；原项目由领导会决策的，同样回领导会。

**限额以上的内部档位**（附件2）：200 万至 500 万，链条终点是交发集团业务分管领导主持的联审会；500 万至 1000 万，终点是交发集团总经理主持的联审会；1000 万至 2000 万，中间增加泉运集团董事会，终点仍是交发集团总经理主持的联审会；2000 万及以上，终点升为交发集团董事长主持的联审会。金额越高，经过的层级越多，这是设计意图而非冗余。

## A1 — 文件中的应用 (Past Application)

### 案例 1：本部 8000 元办公用品与 3 万元维保的差别
- **问题**：两笔都不上会，为什么流转路径不同。
- **方法的使用**：1 万元以下只需会签单报分管领导；1 万至 20 万元同样走会签单，但必须经合规风控部、纪检室、财务部会签。
- **结论**：金额不变时，会签的强制部门会变，这是内控强度的梯度设计。
- **来源**：附件2 对照表"泉运集团本部"栏。

### 案例 2：权属企业 60 万元采购为什么不能自己拍板
- **问题**：权属企业班子会已通过，能否直接签合同。
- **方法的使用**：50 万至 200 万属限额以下由集团审批，权属企业须内部决策后上请示，经集团采购领导小组会、总经理办公会，再由归口部室按会议意见批复。
- **结论**：内部决策只是必要条件，不是充分条件，缺少集团批复即属越权。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这张卡

1. 提报采购前要确认走会签单还是上会，上哪一个会。
2. 预算调整后，判断是否要重新走一遍审批。
3. 权属企业问"我们班子会定了能不能直接干"。
4. 审计或巡察问"这笔 180 万元的项目为什么没有董事会记录"。

### 语言信号

- "这笔该谁批 / 上什么会"
- "预算超了要不要重新报"
- "我们有没有权限自己定"
- "200 万以上是不是要报交发"

### 与相邻能力的区分

- 与 `scope-attribution` 的区别：先确认制度射程，再谈档位；射程内才有档位问题。
- 与 `szyd-routing` 的区别：本卡给的是采购审批链，议事主体归属看事项类型；两者在 50 万元以上物资采购上可能给出不同主体，出现分歧时必须停下核对（见 `szyd-routing` 的边界一节）。
- 与 `procurement-method` 的区别：本卡决定"谁批"，采购方式卡决定"怎么买"，采购方式本身也是审批内容之一。

## E — 可执行步骤 (Execution)

1. **取得估算价与预算状态**
   - 完成标准：拿到单项或批量估算价的具体数字、是否列入年度预算、是否存在超预算及增幅与增额。
2. **定档**
   - 完成标准：输出档位标签之一：限额以上（≥200万）、20万–50万、50万–200万、1万–20万、1万以下；并写明"以上含本数、以下不含本数"。
3. **定主体**
   - 完成标准：写明是本部还是权属企业，据此选择对应链条。
4. **画出完整链条**
   - 完成标准：从发起人开始，逐节点写出会议或审批人，直到最终批复单位；限额以上必须出现交发集团节点。
5. **检查预算状态分支**
   - 完成标准：预算外给出"先纳入预算、再研究采购"的两步结论；超预算给出"是否重新报批、回到哪一级"的判断，并列出触发判断的三个数值。
6. **标注材料**
   - 完成标准：说明需附的会议纪要、请示文、购建说明（必要性、经济性、金额合理性、风险管控措施）等，缺项即提示补齐。

## B — 边界与停止条件 (Boundary)

- 交发集团本部自身的流程（50 万以下参照已批预算内、50 万至 100 万分管领导专题会、100 万以上总经理办公会）出自泉交发〔2026〕62号 第十六条，适用于交发集团本部，不适用于泉运集团本部；混用会造成档位错位。
- 权属一级企业对二级企业的审批权限，交发集团制度明确"一律不得下放至权属二级企业"，泉运集团制度未单列此条，涉及二级企业时以更严的上位规定为准。
- 附件2 标注"动态更新"，若与正文冲突以正文条款为骨架、以最新版附件为操作细节，并在结论中注明所依据的版本。
- 金额无法确定、或"单项"与"批量"的归集口径有争议时停止给结论，先由采购需求单位书面确认估算口径。
