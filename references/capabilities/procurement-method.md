# 采购方式选择与例外

## R — 原文 (Reading)

> 限额以上项目必须进行招标，除进入公共资源交易中心和产权交易中心的项目外，应进入泉州国资阳光集中采购交易平台招标。采购需求单位不得将应当以公开招标方式采购的货物或者服务化整为零或者以其他任何方式规避公开招标采购。

> 依法依规必须进行招标的项目，应当公开招标；但有下列情形之一的，经交发集团批准，报市国资委备案后，可以采用邀请招标，被邀请的单位不得少于3家。

> 限额以下采购项目，采购需求单位可选用"公开招标、邀请招标、竞争性谈判、竞争性磋商、竞价、询价、合作谈判采购、直接采购、单一来源采购、内部采购、其他"等采购方式。

来源：闽泉运综合〔2026〕60号 第二十六条至第二十九条。

## I — 方法论骨架 (Interpretation)

采购方式是"应不应该招标 → 能不能合法地不招标 → 用什么替代方式"的三段判断，不是自由选择。

**第一段：限额以上必须招标。** 200 万元及以上，默认公开招标。交易场所除公共资源交易中心、产权交易中心已覆盖的项目外，一律进泉州国资阳光集中采购交易平台。这里的红线是化整为零：把一个项目拆成若干个 190 万元，形式上每个都在限额以下，实质上仍在规避公开招标，属于明令禁止的行为，责任在采购需求单位。

**第二段：能不能合法地改成邀请招标或单一来源。** 两条路径都要"经交发集团批准、报市国资委备案"这道双重手续，缺一道就是程序违法。

邀请招标的五种情形：涉及国家安全或国家秘密不宜公开；技术复杂或有特殊专业要求，只有少数几家潜在投标人；公开招标费用占项目总价值比例过大而不经济；受自然环境限制只有少量潜在投标人；法律法规规章规定的其他情形。被邀请单位不得少于三家。

单一来源（即依法可不招标）的五种情形：只有一家合格供应商；需用不可替代的专利或专有技术且无合适替代；需向原中标人采购否则影响施工或功能配套，或合同已预先约定后续扩充；对生产经营可能造成重大影响的应急或紧急采购；法律法规规定的其他特殊情形。

**第三段：限额以下用什么方式。** 十一种方式可选：公开招标、邀请招标、竞争性谈判、竞争性磋商、竞价、询价、合作谈判采购、直接采购、单一来源采购、内部采购、其他。选择本身要经内控制度和审批程序，报集团批准后才生效。50 万元及以上的限额以下项目仍要进阳光平台交易，四类例外是涉密、抢险救灾物资、集团内部采购、已中标项目的专业分包与劳务分包及设备材料采购；50 万元以下鼓励进场或数字商城直采。

**流标是独立分支，不是重新招标的同义词。** 首次流标后：没改招标文件和条件的，可自行组织第二次招标；打算改的，要先报交发集团招标采购中心审定并报运营管理部备案。第二次也流标的，报交发集团批准并报市国资委备案后才能转为其他方式；不转方式的，重复第一次流标的处理。

## A1 — 文件中的应用 (Past Application)

### 案例 1：为什么会给"单一来源"加上"应急或紧急"这一条
- **问题**：抢险物资来不及走公开招标，制度上如何留口子而不失约束。
- **方法的使用**：把"对生产经营可能造成重大影响的应急或紧急采购"列入可不招标情形，但保留交发集团批准和市国资委备案两道手续，并要求事后补齐材料（配合应急采购的五个工作日补件规则）。
- **结论**：例外不是免审批，而是换审批路径加事后补救。
- **来源**：第二十七条第二项、第二十五条第四项。

### 案例 2：总包已中标后对外分包为什么还要报批
- **问题**：信息工程承揽的已中标项目，把专业分包、劳务分包、设备材料采购再发包出去，算不算新的采购。
- **方法的使用**：算，且不得化整为零；分包方式要整体批量上报交发集团，限额以下报分管领导、限额以上报总经理，以暂估价形式包含在总承包范围内且达到国家规定规模标准的，仍应依法招标。
- **结论**：分包不因"已在总包内"而豁免审批，反而要求整体批量上报以防止逐笔规避。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这张卡

1. 项目要报采购方式，需要论证为什么不是公开招标。
2. 公开招标流标，判断下一步能不能直接谈。
3. 限额以下项目想用直接采购或内部采购，确认是否可行。
4. 检查时被质疑"这个项目是不是拆标了"。

### 语言信号

- "能不能不招标 / 走单一来源"
- "邀请招标要几家"
- "流标了怎么办"
- "50 万以上要不要上平台"

### 与相邻能力的区分

- 与 `approval-route` 的区别：审批链回答"谁批"，本卡回答"批的是什么方式"；采购方式的确定本身是审批事项之一，两卡需同时输出。
- 与 `internal-pricing` 的区别：内部采购是方式之一，本卡决定能不能用内部采购，定价卡决定用了之后按什么价结算。

## E — 可执行步骤 (Execution)

1. **确认是否属限额以上**
   - 完成标准：给出估算价与档位，200 万元及以上判定为必须招标。
2. **确认交易场所**
   - 完成标准：写明进公共资源交易中心、产权交易中心还是泉州国资阳光集中采购交易平台；并说明依据。
3. **判定例外情形**
   - 完成标准：逐条对照邀请招标五情形与单一来源五情形，输出"命中第 N 项"或"均不命中"；命中时同时列出"交发集团批准 + 市国资委备案"两道手续与"被邀请不少于三家"（邀请招标时）。
4. **检查拆分风险**
   - 完成标准：核对是否存在同一标的、同一需求、同一时间段被拆成多笔，若存在则明确提示化整为零风险并拒绝按拆分后的档位出结论。
5. **限额以下列方式清单**
   - 完成标准：给出可选方式范围，并按 50 万元分界说明是否强制进阳光平台及是否落入四类例外。
6. **流标分支处理**
   - 完成标准：区分"未修改文件"与"拟修改文件"两条路径，给出是否需报招标采购中心审定与运营管理部备案；二次流标给出转方式的前置条件。

## B — 边界与停止条件 (Boundary)

- 涉及国家安全或国家秘密的项目，判断标准由保密与安全部门认定，本卡只引用条文，不作秘密事项认定。
- 采用财政性资金的采购，采购方式还要报交发集团分管领导专题会研究（第二十三条），本卡不替代政府采购监管程序。
- 议价空间与市场价合理性不在本卡范围；本卡只判程序。
- 当同一项目同时符合邀请招标与单一来源两类情形时，优先选限制竞争程度更低的邀请招标，除非只有唯一供应商；若无法确认供应商数量，停止给结论并要求市场调研结果。
