# 决策规则速查 — 泉运集团非工程类采购与"三重一大"决策制度汇编

| 能力 | 一句话规则 |
|---|---|
| 射程判定与归口归属 | 先确认这笔采购归不归泉运集团采购办法管，再按标的找到归口部室。 |
| 金额分档与审批链 | 用估算价和预算状态定位档位，输出从发起人到最终审批人的完整链条。 |
| 采购方式选择与例外 | 先看是否必须招标，再看能否合规地不招标，最后看限额以下可选方式的清单。 |
| 零星小额归集与应急采购 | 常规小额走月度归集，真紧急才先采购、5个工作日内补齐全套手续。 |
| 内部采购定价标准 | 按标的类型套用上浮率或下浮率，物资上浮不超5%，服务下浮不低于30%。 |
| 台账、备案与报送节奏 | 按 5 个工作日、每季度、每年三个节奏对表，配齐八张附件表。 |
| 三重一大议事主体归属 | 先判四类事项中的哪一类，再按清单落到具体议事主体，党委会只做前置研究。 |
| 三重一大六步决策程序 | 动议、论证、会议、记录、报告、执行变更六步，一步不能省。 |
| 廉洁红线、监督与追责 | 七项禁止行为加三年黑名单，监督覆盖全流程，追责看是否明确反对并留痕。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
