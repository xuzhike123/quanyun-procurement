# quanyun-procurement

把福建省泉运实业集团有限公司（泉运集团）的三份现行规章蒸馏成的一套可执行 Agent Skill：不问"书里写了什么"，而问"这笔采购该谁批、这个事项该上哪个会"。

## 这套 Skill 解决什么问题

国企采购与决策的难点不在条文多少，而在三个断点：**金额落在哪个档、归口是哪个部室、事项归哪个议事主体**。这套 Skill 把散在 11 章 54 条里的规则压成 9 张能力卡，每张卡都给出可执行步骤与判停条件。

覆盖范围：

- 制度射程判定（工程、工会经费、商业流通、品牌代理等六类例外）
- 金额分档与审批链（1 万 / 20 万 / 50 万 / 200 万 / 500 万 / 1000 万 / 2000 万）
- 采购方式选择与例外（公开招标、邀请招标五情形、单一来源五情形、流标二次招标）
- 零星小额月度归集与应急采购 5 个工作日补件
- 内部采购定价（上浮 5%、下浮 30% 等六档比率）
- 台账、备案与季度年度报送节奏
- 三重一大议事主体归属（党委会 13 项 / 董事会 19 项 / 总经理办公会 12 项及金额阈值）
- 三重一大六步决策程序与追认、零报告
- 廉洁红线、监督分工与追责免责

## 安装

用户级安装（所有项目可用）：

```bash
git clone https://github.com/<your-name>/quanyun-procurement.git ~/.workbuddy/skills/quanyun-procurement
```

项目级安装（只在某个项目可用）：把仓库克隆到 `<项目>/.workbuddy/skills/quanyun-procurement`。

安装后新开一个任务即可触发，例如：

- 「权属企业要买 60 万元车辆保险，预算内，怎么走」
- 「150 万元的物资采购要不要上董事会」
- 「设备故障急着买，能不能先买后补」

## 已知问题

`books/quanyun-procurement/needs-review.md` 记录了 6 项待核查事项，其中最关键的一条是**条文冲突**：50 万元（不含）以上物资采购的决策主体，三重一大办法指向董事会，采购办法及其附件 2 指向总经理办公会，两份文件同日印发。本 Skill 在该区间不自行取舍，会停下提示人工确认。
