# qycg-skill（仓库沿原名 quanyun-procurement）

把福建省泉运实业集团有限公司（泉运集团）与泉州交通发展集团（交发集团）的现行采购规章蒸馏成的一套可执行 Agent Skill：不问"书里写了什么"，而问"这笔采购该谁批、这个事项该上哪个会、这份招标文件挂网前要不要过联合会审"。

> 技能名已统一为 `qycg-skill`（与本地安装版及开放平台上传包一致），GitHub 仓库名保留 `quanyun-procurement` 不变。

## 这套 Skill 解决什么问题

国企采购与决策的难点不在条文多少，而在三个断点：**金额落在哪个档、归口是哪个部室、事项归哪个议事主体**。这套 Skill 把散在四份文件里的规则压成 10 张能力卡，每张卡都给出可执行步骤与判停条件。

覆盖范围：

- 制度射程判定（工程、工会经费、商业流通、品牌代理等六类例外）
- 金额分档与审批链（1 万 / 20 万 / 50 万 / 200 万 / 500 万 / 1000 万 / 2000 万）
- 采购方式选择与例外（公开招标、邀请招标五情形、单一来源五情形、流标二次招标）
- 零星小额月度归集与应急采购 5 个工作日补件
- 内部采购定价（上浮 5%、下浮 30% 等六档比率）
- 台账、备案与季度年度报送节奏
- 三重一大议事主体归属（党委会 13 项 / 董事会 19 项 / 总经理办公会 12 项及金额阈值）
- 三重一大六步决策程序与追认、零报告
- 廉洁红线、监督分工与追责免责
- **招标文件联合会审（v1.1 新增）**：依法必须招标工程 / 非工程类与工程服务类 200 万元（含）以上的招标文件，挂网前须经交发集团联合会审——八步流程、配套材料、一次审结、公示后 5 个工作日 OA 备案
- **调用前置信息采集门禁（v1.3 新增）**：调用后先核对必写 6 项与命中的场景补写项，未填齐前只输出「信息采集表」，不给任何流程、档位、审批主体、采购方式或条文结论；纯术语 / 整书概览类问题豁免

## 安装

用户级安装（所有项目可用）：

```bash
git clone https://github.com/xuzhike123/quanyun-procurement.git ~/.workbuddy/skills/qycg-skill
```

项目级安装（只在某个项目可用）：把仓库克隆到 `<项目>/.workbuddy/skills/qycg-skill`。

安装后新开一个任务即可触发。**v1.3.0 起会先执行信息采集门禁**：必写 6 项（采购主体、采购标的、估算价及计价口径、预算状态、是否属工程、资金来源与射程例外）与命中的场景项未填齐时，只返回「信息采集表」；补齐后才出流程与依据。填写模板见 `references/intake-checklist.md` 第六节。

示例（信息齐备，可直接出结论）：

- 「集团本部采购 60 万元车辆保险，预算内、非工程、自有资金，怎么走」
- 「150 万元的物资采购，权属企业已内部决策，要不要上董事会」
- 「这批 300 万的设备招标文件，非工程类、预算内，挂网前要办什么手续」

## 已知问题与已消解的分歧

`books/quanyun-procurement/needs-review.md` 记录来源缺口与适用注意项。

- **已消解（v1.2.0）**：50 万元（不含）以上物资采购的决策主体。60号办法第二十二条（二）1 末句把采购项目的金额判断权转致给三重一大办法，78号办法第六条 1（4）据此把该类事项列为董事会审议事项。本 Skill 现按**董事会**口径给出治理主体，采购领导小组专题会等审批链环节照常履行、两套会议并存留痕，直接给出结论而不再判停；集团后续解释口径或权属企业更严制度优先。
- **仍待核查**：供应商评价办法（闽泉运综合〔2026〕33号）等外部文件原文未提供；附件2 标注"动态更新"，与正文存在潜在漂移；权属企业备案制度未取得。

## 生成方式

由 [cangjie-skill](https://github.com/kangarooking/cangjie-skill) v2.5.0 的 RIA-TV++ 流水线生成：v1.0 九项能力全部通过三重验证，全部保留在单一入口内（single 模式）；v1.1 为增量更新（新增能力卡直接同步自安装版并重算清单哈希）；v1.2 为条文复核后的口径修正（编译产物与流水线事实源同步修订）；v1.3 新增调用前置信息采集门禁（全书卡 + 入口硬规则，能力卡数不变）。编译产物通过 `validate_skill_pack.py` 校验（0 error / 0 warning）。
