# 泉运集团采购归口管理部室一览表

来源：闽泉运综合〔2026〕60号 附件1。归口按采购标的类型确定，与金额无关。

| 采购类型 | 具体内容 | 归口管理部室 |
|---|---|---|
| 运输工具相关采购 | 营业性车辆（出租车、公务车、公交车、客运车辆、货车、租赁车、非急救转运车）；其他车辆（叉车、挂车、工具车等） | 安机部 |
| 运输工具相关采购 | 营业性船舶 | 安机部 |
| 运输工具相关采购 | 营运车辆保险采购 | 安机部 |
| 汽车服务相关采购 | 车辆检测设备、维修设备、维修配件及原辅材料（非贸易用）、新能源汽车充电桩 | 运营部 |
| 汽车服务相关采购 | 车辆技术相关 | 安机部 |
| 安全及应急类采购 | 各类监管平台（校车、公务车、渣土车等）的设备采购与运维服务 | 相关业务部室（安机部配合） |
| 安全及应急类采购 | 安防类设施设备（物理防护、技术防护、出入口控制、安全监控、防爆安检等）及其维保服务 | 安机部 |
| 安全及应急类采购 | 消防设施（不含"三同时"要求初期投入的安全设施）、网络安全设备及其维保服务 | 安机部 |
| 安全及应急类采购 | 应急、抢险设施设备 | 安机部 |
| 安全及应急类采购 | 涉及生命安全、危险性较大的设备及其维保服务 | 安机部 |
| 信息化建设采购 | 集团信息化平台及各类系统的建设、运维服务，应用软件开发设计 | 运营部相关业务部室 |
| 信息化建设采购 | 投资用于经营的信息化设备设施（网络设备及系统、广播系统、灯箱广告、电子屏幕、显示器、会务系统、投影仪等） | 相关业务部室 |
| 信息化建设采购 | 用于生产的专用型信息设备（需与主管部室系统对接的计算机及打印机等） | 相关业务部室 |
| 信息化建设采购 | 用于办公的信息化设备设施（计算机设备、计算机软件、辅助设备、通信设备、投影仪、显示屏、打印机、传真机等） | 综合部 |
| 后勤保障类采购 | 集团本部物业（设施设备零星修缮、保安保洁、绿化维护、消杀等） | 综合部 |
| 后勤保障类采购 | 空调设备的采购、安装、维修、清洗 | 综合部 |
| 后勤保障类采购 | 办公用品（笔记本、纸、笔、订书机、其他低值易耗品） | 综合部 |
| 后勤保障类采购 | 办公电器采购及维修（录音笔、碎纸机、净水机组、电冰箱等） | 综合部 |
| 后勤保障类采购 | 办公家具及维修（办公桌椅、会议桌椅、文件柜、沙发、茶几） | 综合部 |
| 后勤保障类采购 | 办公生活类用品（应急值班食物储备、医疗物资、驱蚊杀虫用品、会务用水等） | 综合部 |
| 后勤保障类采购 | 公务用车租赁服务 | 综合部 |
| 咨询服务类采购 | 咨询、经纪、鉴证、调查、物业、租赁、代理 | 相关业务部室 |
| 咨询服务类采购 | 法律 | 风控部相关业务部室 |
| 咨询服务类采购 | 审计、评估（含年度常规评估、业务类评估）、会计服务 | 财务部相关业务部室 |
| 咨询服务类采购 | 企业文化建设、企业规划编制 | 综合部 |
| 咨询服务类采购 | 企业宣传、公关、活动策划、会务服务、广告媒体服务 | 相关部室 |
| 咨询服务类采购 | 档案整理 | 相关档案管理部室 |
| 咨询服务类采购 | 测绘服务（办理土地、房产等权证） | 综合部 |
| 职工相关采购 | 工作服及劳保用品 | 人力部 |
| 职工相关采购 | 培训 | 相关需求部室 |
| 职工相关采购 | 职工体检、文艺体育等 | 工会 |
| 生产经营性采购（以上已归类除外） | 车站、物流仓储、港口航线等业务运营相关采购 | 运营部 |
| 生产经营性采购 | 资产及项目等业务运营相关采购（如泉运商贸、园服公司相关项目） | 相关业务部室 |
| 生产经营性采购 | 汽车服务等业务运营相关采购 | 相关业务部室 |

注：其他未尽事宜，结合立项原因、技术指标要求、部室职责分工等因素划分归口管理部室。
