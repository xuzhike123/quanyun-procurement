# 精华版：一篇文章看懂泉运集团的采购与决策规则

## 一、整套制度其实只回答四个问题

1. **这事归不归采购办法管？** 非工程类的货物和服务归；工程建设项目、工会经费等非行政支出的限额以下采购、商业流通与品牌代理采购不归。
2. **该谁批？** 200 万元及以上报交发集团；200 万元以下的由泉运集团批，权属企业没有审批权。
3. **怎么买？** 限额以上必须招标；限额以下十一种方式可选；想不公开招标，必须过"交发集团批准 + 市国资委备案"这道门。
4. **事由谁定？** 采购项目走采购审批链；治理层面的重大事项走三重一大，看事项类型分派给党委会、董事会或总经理办公会。

## 二、金额台阶：记住 20、50、200 三个数

| 估算价 | 谁批 | 走什么形式 |
|---|---|---|
| 1 万元以下（本部） | 集团分管领导 | 采购会签单 |
| 1 万–20 万（本部） | 集团分管领导 | 会签单 + 合规风控部、纪检室、财务部必签 |
| 20 万–50 万 | 集团采购领导小组 | 专题会 |
| 50 万–200 万 | 集团总经理办公会 | 领导小组会 → 总经理办公会 |
| 200 万–500 万 | 交发集团业务分管领导 | 内部决策 → 请示 → 领导小组会 → 总经理办公会 → 联审会 |
| 500 万–1000 万 | 交发集团总经理 | 同上级链，联审会由总经理主持 |
| 1000 万–2000 万 | 交发集团总经理 | 中间增加泉运集团董事会 |
| 2000 万及以上 | 交发集团董事长 | 董事会 → 董事长主持联审会 |

权属企业还有两条专属规则：20 万元以下按"是否可归集、是否达三重一大标准"分三种走法；20 万至 200 万元一律是"内部决策 → 上请示 → 集团会议 → 归口部室批复"。权属企业自己开会通过，不等于可以签合同。

## 三、四个高频场景的完整答案

**场景一：临时要买一批办公用品，3 万元。**
归属综合部；本部走会签单，必须经合规风控部、纪检室、财务部会签，再由分管领导审批。若发生在权属企业且属常规性重复性采购，应归入月度零星小额需求表，每月 25 日前汇总报批。

**场景二：一个 180 万元的项目，领导想指定供应商。**
180 万元属限额以下，但 50 万元以上必须进泉州国资阳光集中采购交易平台。要指定供应商，只有走单一来源，条件是"只有一家合格供应商"等五类情形之一，且须经交发集团批准、报市国资委备案。没有这两道手续的指定，属程序违法；把它拆成四个 45 万元，属化整为零。

**场景三：设备突发故障，必须马上买。**
只有落在抢险救灾、安全生产保障、突发故障处置、紧急经营保障四类，且直接威胁人身安全、企业正常运营或重大资产安全时，才可以先买。之后在紧急情形解除起 5 个工作日内补齐审批、情况说明、佐证材料并归档。注意起算点是"解除"，不是"发生"。

**场景四：要不要上董事会？**
不要先看金额，先看事项类型。资产处置看账面净值 300 万元；资产租赁看年使用费 300 万元、或累计 2000 万元、或租期超过 5 年；对外捐赠看 5 万元；超预算与预算外资金看单笔 50 万元；预算外对外融资看 2000 万元；专项资金与非生产性资金看 200 万元。落在门槛下方，到总经理办公会。

## 四、最容易出错的六个点

1. **"以上"含本数，"以下"不含本数。** 200 万元整属限额以上，不属限额以下。
2. **审批权不下放。** 权属企业可以提需求、做执行、走内部决策，但没有审批决策权。
3. **紧缺材料也不能省前置。** 应急采购免的是事前审批，不免事后审批，更不免三重一大中不可省略的部分。
4. **流标不是重新招标的同义词。** 要改招标文件的，得先报交发集团招标采购中心审定并报运营管理部备案。
5. **记录里的"不同意见"是免责凭证。** 明确反对、理由充分、未被采纳，三者齐备才可免予责任追究；没记录就等于没反对。
6. **党委前置研究不是前置决定。** 它形成意见，不产生决定效力。

## 五、内部采购定价一张表

- 物资类（含除信息工程成品硬件外的设备、福利商品）：成本价上浮不超过 5%。
- 服务类：有国标或行业指导价的，下浮不低于 30%；旅游包车下浮不低于 10%；广告制作成本价上浮不超过 10%；机械设备租赁按不含税报价上浮不超过 5%。
- 信息工程：自主研发下浮不低于 5%；成品软硬件按进价上浮不超过 10%。
- 公开招投标取得且金额已明确的项目：由双方协商确定，不套比率。

## 六、时间节点清单

| 节点 | 时限 | 报送对象 |
|---|---|---|
| 零星小额需求汇总 | 每月 25 日前 | 集团（经 OA 会签单） |
| 限额以上采购备案表 | 完成招标后 5 个工作日内 | 集团采购办 |
| 应急采购补件 | 紧急情形解除后 5 个工作日内 | 内部归档 |
| 万元以上采购台账 | 每季度终了 5 个工作日内 | 集团采购办 |
| 限额以上备案台账 | 每季度终了 5 个工作日内 | 交发集团运营管理部（由采购办报） |
| 年度执行情况 | 次年 1 月 5 日前 | 集团 |
| 三重一大决策情况 | 每月 10 日前（无事项亦须零报告） | 集团综合部 |

## 七、这份精华版没解决的问题

三份文件对"50 万元以上物资采购由董事会还是总经理办公会决策"给出了不同答案，且两份文件同日印发。这不是读者理解错了，而是制度文本本身存在冲突。遇到该区间，唯一稳妥的做法是停下核实、按更严者执行或请示，不要靠解释技巧绕过。

同理，供应商评价的具体标准（闽泉运综合〔2026〕33号）与多份上级文件（泉交发〔2026〕42号等）本次未提供，涉及这些细则时须另行查原文。
